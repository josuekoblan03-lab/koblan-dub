# Koblan Dub

**Rendre une vidéo ou un audio compréhensible dans une autre langue, sur son PC, gratuitement.**

**Site : [koblan-dub.vercel.app](https://koblan-dub.vercel.app)**

Koblan Dub est un atelier complet de traduction et de doublage pour Windows : il transcrit la parole, traduit les sous-titres, double la vidéo avec une voix de synthèse et fusionne le tout en un MP4 prêt à regarder.

## Ce que fait Koblan Dub

| Mode | Usage |
|---|---|
| Traduire une vidéo | transcription, traduction, doublage et sous-titres en une seule fois |
| Transcrire et traduire | obtenir les sous-titres (SRT) d'une vidéo, traduits ou non |
| Parole vers texte | transformer un audio ou une vidéo en texte |
| Traduire des SRT en lot | traduire plusieurs fichiers de sous-titres d'un coup |
| Doublage en lot | créer la voix à partir de fichiers SRT |
| Doublage multi-voix | une voix différente par réplique |
| Fusion vidéo + sous-titres | incruster des sous-titres dans des vidéos, en lot |

Le menu **Outils** ajoute : sous-titres bilingues (fusion de 2 SRT), conversion SRT/ASS/VTT/TXT, séparation voix et musique de fond, fusion vidéo/audio/sous-titres.

Une trentaine de langues au départ comme à l'arrivée (français, anglais, espagnol, portugais, arabe, chinois, russe, allemand, japonais, turc…). La transcription et la voix française intégrée fonctionnent **hors ligne** ; la traduction et les voix des autres langues passent par internet (gratuitement).

## Télécharger et installer

Le plus simple : le bouton **Tout télécharger** sur [koblan-dub.vercel.app](https://koblan-dub.vercel.app/#telecharger). Sinon, sur la page [Releases](https://github.com/josuekoblan03-lab/koblan-dub/releases/latest), téléchargez **les 4 fichiers** :

- `KoblanDub-Setup.exe`
- `KoblanDub-Setup-1.bin`
- `KoblanDub-Setup-2.bin`
- `KoblanDub-Setup-3.bin`

1. Mettez-les **dans le même dossier**, sans les renommer.
2. Lancez `KoblanDub-Setup.exe`.
3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires** puis **Exécuter quand même**.

Configuration requise : Windows 10 ou 11 (64 bits), environ 9 Go d'espace libre. L'installation prend une dizaine de minutes, une seule fois.

Les empreintes SHA-256 des fichiers sont dans [SHA256SUMS.txt](SHA256SUMS.txt).
